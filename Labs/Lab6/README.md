# ARTI308 – Lab 6: Linear Regression
---
## Overview
This lab applies **Linear Regression** to analyze customer behavior using the **Ecommerce Customers dataset**.
The goal is to predict **Yearly Amount Spent** based on user activity metrics.
---
## Dataset

**Ecommerce Customers.csv**

---
## Tasks Performed

* Data exploration and visualization
* Correlation analysis
* Train-test data split
* Training a Linear Regression model
* Prediction and model evaluation (MAE, MSE, RMSE)


---
**Tools:** Python, Pandas, Seaborn, Scikit-learn
