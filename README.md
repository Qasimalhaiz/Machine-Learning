# BNPL (Buy Now, Pay Later) Prediction

This project is part of the ARTI308 Lab5 course, where we implement a **K-Nearest Neighbors (KNN)** classifier for predicting **Buy Now, Pay Later (BNPL)** outcomes. The dataset contains various features, and the goal is to predict the target column indicating the outcome based on these features.

## Project Structure

- `ARTI308_Lab5_BNPL.ipynb`: The Jupyter Notebook containing the implementation of the KNN algorithm, data preprocessing, feature engineering, and evaluation.
- `bnpl_dataset.csv`: The dataset used in this project, containing multiple features used for training the KNN classifier.

## Requirements

Before running the code, ensure that you have the following Python libraries installed:

- pandas
- numpy
- scikit-learn (optional if you wish to use any ML models)
